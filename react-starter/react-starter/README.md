# React Starter Project

Is project ko use karke aap koi bhi page design kar sakte hain.

## Setup karne ke steps:

1. Node.js install hona chahiye (v16 ya usse upar).
2. Terminal mein project folder open karein.
3. Dependencies install karein:
   ```
   npm install
   ```
4. Development server start karein:
   ```
   npm run dev
   ```
5. Browser mein diya gaya link (usually `http://localhost:5173`) open karein.

## Kahan design karein?

- `src/App.jsx` — yahan apna page ka structure/content likhein.
- `src/App.css` — yahan apna styling customize karein.
- `src/index.css` — global styles ke liye.

Jitna chahein utna add/remove kar sakte hain — components, images, forms, sab kuch is folder mein hi rakhein.

Happy designing! 🎨
